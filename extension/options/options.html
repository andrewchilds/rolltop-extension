AI sorting

With an Anthropic API key, Rolltop asks Claude to group tabs by what you are doing. Without one, tabs are grouped by website and nothing leaves this computer.

What is sent when a tab needs sorting: its title, its address without the query string or fragment, and the names of your existing groups with a few of their tab titles. Private windows are never sent. The key is stored unencrypted in this Firefox profile.

claude-opus-5-5 is the default. claude-haiku-5-5 costs far less.

Auto-tidy

Archived tabs are closed but stay searchable in the sidebar. Pinned tabs and tabs in pinned groups are never archived.

Sorting log

The last 20 sorting runs: the tabs that needed a group, where each went and why, and the groups the model was shown. Kept on this computer only.
